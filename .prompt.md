# BLT Dashboard - SAW Auto-Fill Prompt

## Context
This is a BLT (Bantuan Langsung Tunai) dashboard system using Simple Additive Weighting (SAW) method for beneficiary scoring.

## Task: Auto-fill SAW Penilaian Criteria from Penghasilan Bulanan

When editing a peserta (beneficiary) in **pages/peserta/edit.php**, if the user enters or changes the "Penghasilan/Bulan (Rp)" value, automatically:

1. **Fetch the SAW scoring rules** from the database:
   - Check `saw_kriteria` table for C1 (which is the economic/income criteria)
   - Get the score ranges from `saw_sub_kriteria` table

2. **Map penghasilan_bulanan to SAW scoring** using the rules:
   - For each sub-kriteria entry for C1, apply the income thresholds
   - Automatically populate the SAW penilaian fields if a penilaian record exists

3. **JavaScript behavior**:
   - Listen to `penghasilan_bulanan` input field for change events
   - Call an API endpoint to calculate the appropriate SAW score
   - Auto-populate related scoring fields in real-time
   - Show the recommended score to the user

## Implementation Notes
- Create an API endpoint at `api/calculate_saw_from_income.php`
- Return JSON with the calculated score and sub-kriteria details
- Update only if C1 kriteria exists and is active
- Log the automatic update for audit trail
